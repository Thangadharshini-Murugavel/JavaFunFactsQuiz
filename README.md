
# Java Fun Facts Quiz 🎯

A console-based quiz application developed using Java. Users can select a category, answer multiple-choice questions, learn interesting facts, and view their final scores.

## 🎬 Demo Video

[▶ Watch Java Fun Facts Quiz Demo](https://youtu.be/04u7B_6MQ9A)

## ✨ Features

- Three categories: Space, Animals, and Human Body
- Five questions in each category
- Randomized question order
- Multiple-choice answers
- Input validation
- Instant feedback for answers
- Interesting facts for incorrect answers
- Final score and percentage calculation
- Option to play again

## 🛠️ Technologies Used

- Java
- ArrayList
- Collections
- Scanner
- Exception Handling

## ▶️ How to Run

1. Install JDK.
2. Clone or download this repository.
3. Open the project folder in your terminal.
4. Run the following commands:

Compile:

    javac -encoding UTF-8 Question.java Main.java

Execute:

    java -Dfile.encoding=UTF-8 Main

Alternatively, Windows users can run `run.bat`.
